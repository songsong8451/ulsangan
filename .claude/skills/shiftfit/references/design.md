# ShiftFit 디자인 토큰 (index.html `:root`에서 추출)

다크 테마 하나. 숲속 밤 + 라임 민트 강조. ERP(남색·핑크)와는 별개 브랜드이므로 섞지 않는다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#0b1110` | 바탕 |
| `--panel` / `--panel-2` / `--panel-3` | `#111a17` / `#17211d` / `#1d2924` | 카드 단계 |
| `--line` | `#27342e` | 테두리 |
| `--text` / `--muted` / `--dim` | `#f1f5ef` / `#a1afa6` / `#6e7d73` | 글자 단계 |
| `--mint` / `--mint-2` | `#b8f279` / `#91cc54` | 주 강조(버튼·활성 메뉴·점수) |
| `--amber` | `#f4c875` | 주의 |
| `--red` | `#f19b8e` | 경고 |
| `--blue` | `#a5c5ff` | 수면·정보 |
| `--violet` | `#cfb3ff` | 보조 |
| 카카오 버튼 | `#fee500` / 글자 `#191600` | 카카오 규정색 |

글꼴: Noto Sans KR(한글 본문) · Manrope(숫자·제목) · DM Sans(영문 UI).

## 화면 규칙

- 모바일 우선. 320px까지 확인한 이력 있음, 가로 스크롤 금지(하네스 검사).
- 카드 간격·체크박스 간격(24px) 등은 커밋 이력으로 여러 번 맞춘 값이라 함부로 바꾸지 않는다.
- 문구는 부드러운 존댓말("~해요", "~해 보세요").
- UI 작업 전 `ui-ux-pro-max` 스킬로 접근성(대비·터치 영역 44px)·차트 규칙을 확인한다.
